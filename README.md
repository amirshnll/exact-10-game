# Exact 10

## Short description

Find pairs of numbers that add up to the target.

## Description

Exact 10 is a fast, accessible, multilingual arithmetic game for the browser. It challenges players to select number pairs that reach the required total and includes configurable digits, sound, difficulty, performance statistics, and personal records.

## Purpose

The extension is designed to provide short mental-math practice sessions and help users improve calculation speed, accuracy, and number recognition directly from the browser toolbar.
